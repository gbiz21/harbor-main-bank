# ADR-0001: One active phase at a time; nothing is done until it is in GitHub

Date: 2026-10-31
Phase: all
Status: accepted

## Context
A twelve-month solo project fails by having three things half-built. Status, thinking and finished work were spread across tools with no rule.

## Decision
One active phase per track. A phase is done only when its code applies from empty, its design doc is merged, its validation checklist is ticked with dates, and the tracker is flipped.

## Consequences
New ideas go to the parking lot. The repo is the only source of truth; Notion steers, Obsidian thinks.
